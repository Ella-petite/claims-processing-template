Claims Processing full rebuilt application

Frontend: Claims.Web (standalone Blazor WebAssembly)
BFF: Claims.Bff (API only)
Core backend / system of record: Claims.Api
Shared contracts: Claims.Contracts
Workflow: Claims.Workflow.Functions (Durable Functions + Service Bus trigger)
Payment integration: Claims.PaymentGateway.Api
Payment provider: Claims.PaymentProvider.Mock.Api
Client Registry mock: Claims.Registration.Mock.Api
Policy Manager mock: Claims.Policy.Mock.Api
Rules Engine mock: Claims.Rules.Mock.Api
Fraud Detection mock: Claims.Fraud.Mock.Api
Document processing mock: Claims.DocumentProcessing.Api
Notifications: Claims.Notification.Function
Orchestration: Claims.AppHost (.NET Aspire)

The frontend is intentionally separate from the BFF. Claims.Bff contains no UI or wwwroot and acts only as the frontend-facing API boundary.

Do not commit claims.db, App_Data, bin or obj. Use the supplied .gitignore.
